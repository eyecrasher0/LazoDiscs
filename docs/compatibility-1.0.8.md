## Choosing the LazoDiscs file

- Fabric, Forge and NeoForge: use the file for your exact Minecraft version and loader.
- Paper: prefer `lazodiscs-paper-1.0.8+<minecraft>.jar` whenever present. These native
  Paper builds preserve the silent song registry used by existing 1.0.7 installations.
- Paper versions without a native Paper file, Spigot, Purpur and Folia: use
  `lazodiscs-bukkit-1.0.8.jar`. Install only one LazoDiscs plugin.
- Voice 1 clients on 1.17, 1.18 and 1.18.1: install the matching full Fabric/Forge
  LazoDiscs mod on each client. Forge was not released for Minecraft 1.17.
- Voice 1 clients on Bukkit 1.16.5: use the Fabric or Forge
  `lazodiscs-voice1-client-…-1.0.8+1.16.5.jar` helper. The full 1.16.5 mods target Voice 2.
- Voice 1 clients on Bukkit 1.19/1.19.1: use the Fabric or Forge
  `lazodiscs-voice1-client-…-1.0.8+1.19-1.19.1.jar` client helper. The full
  LazoDiscs mods for those Minecraft versions target Voice 2 instead.

Keep your existing native Paper distribution when upgrading from 1.0.7. Switching
that installation to the universal Bukkit adapter requires migrating native silent
song items and registry entries; this release does not automate that migration.

## Runtime and feature boundaries

Minecraft 1.16.5 mod builds retain Java 8 support; 1.17/1.17.1 Fabric builds use
Java 16. The Bukkit archive supports Java 16, with the JVM required by the chosen
server and Voice release. Stock Paper/Spigot/Purpur 1.16.5 cap Java at 16. Their official Voice 2
plugin needs Java 17, so this combination uses Voice 1 with Java 16. No launcher
version check is bypassed. Minecraft 26.x uses Java 25.

The universal adapter keeps vanilla disc types and PDC recordings. On older Bukkit
servers, stopping the vanilla song uses the native record-stop event; hopper and
redstone behavior follows that server's jukebox API. Newer native Paper builds
use silent songs. Voice 1 supports positional jukebox playback; its extra client
transport uses Voice 1's Opus decoder, audio engine and listener volume settings,
with bounded PCM/OpenAL storage owned and released by LazoDiscs. Listeners must
have an active official Voice 1 session; the LazoDiscs client greeting alone does
not authorize audio delivery. A late Voice connection starts delivery without a
second Minecraft login.
Optional Sophisticated Backpacks integration requires Voice 2.

Minecraft 1.7.10, 1.8.9 and 1.12.2 are excluded because there is no official Plasmo
Voice release for them. Server versions without official Paper/Purpur/Folia builds
are excluded separately even when Spigot or a mod loader exists.

Fabric 1.17 selects Voice 1.2.11. Later Voice 1 jars require a Fabric API release
whose own Minecraft dependency starts at 1.17.1. The published Voice metadata
lists 1.17 broadly, so this constraint is recorded explicitly in
[compatibility-policy.json](../compatibility-policy.json) and checked with a real
Fabric Loader launch.

## Recorded links and diagnostics

Portable recordings retain the complete playable URL, including signed query
parameters. LazoDiscs and its bundled audio/HTTP libraries redact URL credentials,
paths and query values from their logs. Private HTTP protocol debug output is
disabled; unrelated warnings and errors retain their diagnostic details. Stored
recordings obey the current server hearing-range cap when read for playback.
