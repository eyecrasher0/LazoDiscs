# История изменений LazoDiscs

## 1.0.8

- Подготовка первого аудиокадра перед передачей отменяемого воспроизведения предотвращает сбои первого запуска на старых Forge. Первый кадр сохраняется; ошибки декодирования после начала воспроизведения также доходят до игрока.
- На Minecraft 1.16.5 используются доступные серверу методы координат; исключены аннотации зависимостей, вызывавшие конфликт модулей NeoForge.
- Исправление ошибки входа YouTube перенесено на все сборки: игроку выводится “YouTube requires sign-in. Please try another link.”, в консоль — короткое предупреждение. Причины и подробные логи остальных ошибок сохранены.
- Выбирается новейшая совместимая официальная стабильная версия Voice 2, включая архивные 2.0/2.1. Добавлены адаптеры Voice 1 для целей, где совместимый Voice 2 запустить нельзя.
- Добавлены недостающие Fabric/Forge для Minecraft 1.17/1.18/1.18.1 там, где существуют загрузчики, Fabric 1.20.5/1.20.6 и совместимые патчи 1.21.
- Добавлен универсальный Bukkit-плагин для Spigot, Purpur, Folia и дополнительных версий Paper. Сохранена нативная Paper-сборка и реестр бесшумных песен для обновления существующих установок.
- Для Voice 1 нужен клиентский LazoDiscs. Добавлены небольшие клиентские модули Fabric/Forge для Bukkit 1.16.5 и 1.19/1.19.1; используются звуковой движок, декодер и настройки громкости самого Voice 1.
- Обновлены источник YouTube, Jackson, Gson, JSON-java, Commons Codec, Rhino, Fabric Loader/API и совместимые Forge/NeoForge. Для Java 8 сохранён Rhino 1.7.15.1; старые JVM проверяются реальным воспроизведением и выполнением JavaScript.
- Общие адаптеры проверяют границы аудиопакетов и освобождают фильтры логов, загрузки, источники звука и командные псевдонимы при выключении.
- Исправлен первый запуск пластинки на старом Forge при замене незавершённой загрузки; клиентские источники Voice 1 пересоздаются после смены устройства вывода звука.
- Gson/Jackson проверяются реальной обработкой JSON из готового JAR; для чистых сборок используется действующий репозиторий зависимостей Plasmo.
- Добавлена точная матрица зависимостей, закреплённые сборки серверов и воспроизводимые проверки JAR, JVM, бинарных API и временных серверов.

## [1.0.7 Paper] - 2026-11-10

### Добавлено

- Первый выпуск плагина Paper: 21 точная версия сервера от 1.17.1 до 26.3 из списка совместимости стабильного Plasmo Voice 2.1.17, для которых существуют сборки Paper. Модовые сборки не изменены.
- Обычный запуск на указанной Java без флагов обхода проверки версии. Paper 1.16.5 исключён: его штатная Java несовместима с текущим плагином Plasmo Voice.
- Запись, поиск и стирание пластинок через Bukkit-права, сохранение данных на предмете, настройки языка/воспроизведения и позиционный звук Plasmo Voice на аудиодвижке 1.0.7.
- Адаптеры проигрывателей: PDC до 1.21.3, бесшумные песни через датапак с 1.21.4 по 26.2 и реестры на 26.3. Воронки поддерживаются там, где у проигрывателя есть ванильный инвентарь (1.19.4+).
- Изолированные аудиобиблиотеки для старых серверов, отмена загрузки при извлечении/выгрузке, проверка защиты и очистка звука, потоков и команд при отключении.
- Серверные интеграционные проверки с закреплёнными хэшами и матрица GitHub Actions. Требования и различия старых версий — в `paper/README.md`.

## [1.0.7] - 2026-10-13

### Исправлено

- При записи пластинки по ссылке Spotify сохраняется ссылка на выбранную аудиозапись: повторное воспроизведение больше не повторяет поиск Spotify. Подбор Spotify теперь отклоняет посторонние названия, даже если длительность близка.
- Исправлено воспроизведение SoundCloud с потоками AAC/fMP4 HLS, включая короткие ссылки on.soundcloud.com; поддержка прежних аудиоформатов сохранена.
- Восстановлено воспроизведение записанных пластинок в Sophisticated Backpacks на Fabric с новым API SoundHandler в SophisticatedCore. Вместо исходной песни Minecraft играет записанный трек.
- Сохранена поддержка прежнего API обработчиков пластинок SophisticatedCore на Forge и NeoForge, включая версии, где остановка принимает серверный мир.
- Сохранена корректная очистка воспроизведения и обработка завершения трека при остановке, замене и окончании записи в рюкзаке.

### Изменено

- Из релизных файлов удалён устаревший YouTube-модуль LavaPlayer с кодом передачи данных Google-аккаунта стороннему серверу. Воспроизведение и поиск YouTube продолжают работать через youtube-source.
- Остальные источники LavaPlayer регистрируются явно; поддержка SoundCloud и прямых аудиоссылок сохранена.

Набор из 52 сборок Minecraft/загрузчиков и публичные интерфейсы для LazoBoombox сохранены. Нужен Plasmo Voice; для Fabric также нужен Fabric API.

## [1.0.6] - 2026-10-07

### Добавлено

- Добавлена поддержка Forge.
- Добавлены сборки для большего количества версий Minecraft, начиная с 1.16.5, по поддержке стабильного Plasmo Voice 2.1.17. Всего 52 сборки: 25 Fabric, 15 Forge и 12 NeoForge.

### Исправлено

- Исправлена работа проигрывателя при установке и извлечении пользовательских пластинок на поддерживаемых версиях 1.21.x.
- Убраны лишние остановки и перезапуски музыки, когда попытка извлечения оставляет пластинку в проигрывателе.

### Изменено

- Иконка мода заменена на новое изображение 256×256 в меню модов и Plasmo Voice.
- Релизные сборки теперь следуют версиям Minecraft, которые поддерживает стабильный Plasmo Voice 2.1.17. Версии только для старых или beta-выпусков Plasmo Voice не включены.

Нужен Plasmo Voice. Для Fabric также нужен Fabric API.
